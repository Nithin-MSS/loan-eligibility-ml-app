# Loan Eligibility & Credit Scoring System 🏦📊

A Machine Learning–based web application that predicts loan eligibility
and credit risk based on applicant financial and demographic data.

🔗 **Live App**:  
https://loan-eligibility-ml-app-9bgujvzhetkqxzyblfu5zs.streamlit.app

---

## 🔍 Problem Statement
Financial institutions must assess loan applications efficiently while
minimizing default risk. Manual screening is time-consuming and error-prone.

This project automates loan eligibility decisions using Machine Learning.

---

## 🚀 Features
- End-to-end Machine Learning pipeline
- Data preprocessing & feature engineering
- Credit risk–based eligibility decision
- Interactive Streamlit web interface
- Real-time loan eligibility prediction
- Deployed on Streamlit Cloud
